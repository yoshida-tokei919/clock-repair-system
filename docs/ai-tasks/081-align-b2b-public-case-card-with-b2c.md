# AI Task 081: B2B価格事例カードをB2Cカード型に統一

## 目的

`/dev/public-case-gallery-preview` のB2B価格事例を、管理画面・警告一覧のような見た目ではなく、B2C修理事例カードと同じ方向の公開カードUIへ揃える。

## 前提

- 対象は開発用プレビュー画面のみ
- 既存の `/cases/gallery`、`/cases/biz` は変更しない
- DB接続・DB更新は行わない
- CSV / Excel / JSON本体は変更しない
- B2Cでは価格を表示しない
- B2Bでは安全に表示できる価格だけを表示する

## FMP過去案件と新アプリ通常案件の切り分け

FMP過去案件と新アプリ通常Repair案件は、PublicCaseを作るまでの変換ルールを切り分ける。

FMP過去案件では、以下をFMP移行・救済専用ルールとして扱う。

- `○○` プレースホルダー補正
- 読み仮名suffix削除
- `part_without_publishable_work` 救済
- 未紐づけPartItemの価格非表示
- FMP原文からB2B/B2C表示名を生成

新アプリ通常Repair案件では、作業名・部品名・処置・B2B表示名・B2C表示名・価格を、最初からマスタと構造化データから生成する方針とする。

## PublicCase化後の表示共通化

PublicCase化された後は、FMP由来か新アプリ由来かを閲覧者に見分けさせない。

以下は共通化する。

- PublicCase表示UI
- B2C価格非表示
- B2B価格表示
- ブランド / モデル / Ref / Cal の見せ方
- 写真付きカードUI
- B2C/B2B事例ページ

## B2Bで削除した内部管理文言

B2B公開カードから以下の内部管理文言を削除した。

- `要確認`
- `未紐づけ部品`
- `未紐づけ部品 1件は要確認です。価格は表示していません。`
- warning / review / relation状態をそのまま示す表示

未紐づけPartItemは内部的にはレビュー対象のままだが、公開カード上では警告文を出さない。

## B2Bカードの新しい表示方針

B2BカードをB2Cカードと同じ写真付きカード型へ寄せた。

構成は以下。

1. 写真枠
2. ブランド
3. モデルまたはRef/Cal由来タイトル
4. Ref / Cal
5. 修理内容
6. 技術料
7. 交換部品
8. 合計
9. 詳しく見る

## B2B価格表示ルール

価格表示ルールは変更していない。

- `showPriceB2b = true` かつ正の金額がある明細だけ表示
- `showPriceB2b = false` の価格は表示しない
- 0円は表示しない
- 合計は表示対象価格だけで計算
- 未紐づけPartItemの価格は表示しない
- 価格表示対象がない場合は、管理文言ではなく控えめな `参考価格なし` にする

## 未紐づけPartItemの扱い

未紐づけPartItemの価格は表示しない。

公開カード上では `未紐づけ`、`要確認`、`価格は表示していません` などの内部文言を出さない。

## 交換部品ラベル

B2Bカードでは引き続き `交換部品` ラベルを使う。

`部品代` というラベルは使わない。

## B2C表示への影響

B2Cカードの価格非表示方針は変更していない。

B2Cカードの構成も変更していない。

## 変更しなかったもの

- DB接続・DB更新
- migration / seed
- Supabase接続
- `prisma/schema.prisma`
- CSV / Excel / JSON本体
- 既存の `/cases/gallery`
- 既存の `/cases/biz`
- `RepairEntryForm.tsx`
- `PricingRule`
- FMP公開候補生成ロジック
