# AI Task 079: PublicCaseギャラリープレビューのUI表示階層修正

## 目的

`/dev/public-case-gallery-preview` のB2C / B2Bカードで、公開事例として不要な内部判断ラベルを消し、ブランド・モデル・Ref / Cal の表示階層を見直す。

今回は開発用プレビュー画面のUI修正のみで、DB反映やデータ生成ロジックは変更しない。

## 前提

- 対象は `src/app/(app)/dev/public-case-gallery-preview/page.tsx`
- 既存の `/cases/gallery`、`/cases/biz` は変更しない
- DB接続・DB更新は行わない
- CSV / Excel / JSON本体は変更しない
- B2Cでは価格を表示しない

## B2Cで削除した表示

B2Cカード上から、以下の内部確認系表示を削除した。

- 写真準備中
- モデル確認
- 作業名確認
- 部品確認
- 要確認
- 情報少なめ

写真がない場合のグレーの写真枠は残し、カード上の目立つ注意文としては出さない。

## B2C文字階層の修正

B2Cカードではブランドを小さなbadge扱いにせず、カード内の主見出しに近いサイズで表示するようにした。

表示順は以下。

1. ブランド名
2. モデル名またはRef由来のタイトル
3. Ref / Cal
4. 作業内容
5. 詳しく見る

## B2C Ref / Cal 表示の修正

Ref / Cal は `text-xs text-neutral-500` から、より読みやすい `text-sm font-medium text-neutral-700` 相当へ変更した。

モデル名がない場合でも、Ref / Cal がカード情報として読み取れるようにした。

## B2B文字階層の修正

B2Bカードでもブランド名を小さな補足表示にせず、モデル名と同等以上に見えるサイズへ変更した。

表示順は以下。

1. ブランド名
2. モデル名またはRef由来のタイトル
3. Ref / Cal
4. 修理内容・費用
5. 技術料
6. 交換部品
7. 合計

## B2B Ref / Cal 表示の修正

B2Bでも Ref / Cal を読みやすいサイズと濃さに変更した。

業者向け価格事例ではRef / Calが重要情報になるため、薄い補足ではなくカード上部の識別情報として扱う。

## 部品代ラベルを交換部品へ変更

B2B価格表内のラベルを以下のように変更した。

- 変更前: 部品代
- 変更後: 交換部品

表示しているのは交換した部品名と価格のため、金額カテゴリに見える「部品代」よりも「交換部品」の方が実務上自然と判断した。
