# AI Task 059: FMP過去データ公開事例候補数の調査

## 目的

FMP過去修理データから、公開事例候補が実際に何件程度になるかを確認する。

今回は調査のみとし、DB、既存マスタ、既存UI、公開ページ、取り込み処理には接続しない。

## 前提

- FMP過去修理データは約4000件
- 内装修理99件は事例数ではなく作業名ルール数
- 外装修理事例も公開対象
- 外装修理は第3次レビュー25件まで確認済み
- 内外装マスタは未完成のため、今回は既存マスタへ接続しない

- 057: `docs/ai-tasks/057-design-public-case-b2b-b2c.md`
- 058: `docs/ai-tasks/058-implement-internal-repair-public-case-rules.md`

- `docs/data/fmp/source/fmp-repair-export-original.csv`
- `docs/data/fmp/external-repair/外装修理_第3次レビュー候補.xlsx`
- `docs/data/fmp/internal-repair/内装修理_部品名ドリルダウンレビュー用_掲載99件反映版.xlsx`

## 現時点で確認できたデータ所在

- FMP過去修理データCSVはヘッダーなし。057の「事例化データの元情報」の列順を仮ヘッダーとして読み取る必要がある。
- 内装修理Excelには `掲載判定_全件`、`掲載対象_確認済99内`、`掲載しない_未レビュー等`、`掲載方針_概要` がある。
- 内装修理Excelの概要では、原文ユニーク320種類、確認済み99種類、未レビュー221種類、掲載候補62種類、掲載候補（要最終確認）3種類と整理されている。
- 外装修理Excelには `概要`、`第3次_優先レビュー`、`確認済みサマリー`、`判断ルール` がある。
- 外装修理Excelの概要では、外装修理明細総件数1376件、外装修理名ユニーク488種類、確認済みユニーク68種類、未確認ユニーク420種類と整理されている。
- 第3次レビューの優先レビューシートでは、`ヨシダ確認結果` が入っている行が25件あり、内訳はOK 17件、掲載対象外8件。

## 集計すべき件数

- FMP過去データの修理ID総数
- 内装修理明細の総数
- 外装修理明細の総数
- 内装修理ルールにより掲載候補になる明細数
- 外装修理ルールにより掲載候補になる明細数
- 内装または外装のどちらかに掲載候補がある修理ID数
- 内装のみ掲載候補がある修理ID数
- 外装のみ掲載候補がある修理ID数
- 内装・外装の両方に掲載候補がある修理ID数
- 掲載対象外になる明細数
- 未レビューのため掲載しない明細数

## 集計方法案

1. CSVをヘッダーなしとして読み、057の列順で仮ヘッダーを付ける。
2. `内装修理内容1〜3` の非空欄を内装修理明細として数える。
3. `外装修理内容1〜3` の非空欄を外装修理明細として数える。
4. 内装は `掲載判定_全件` の `原文` と完全一致させ、`掲載可否` が `掲載候補` または `掲載候補（要最終確認）` のものを候補扱いする。
5. 外装は `確認済みサマリー` の `原文` と完全一致させ、確認結果があり、外装掲載に使う表示名があるものを候補扱いする。
6. `掲載対象外`、`内装修理へ`、`巻芯は内装へ`、表示名未確定、未確認の外装明細は、今回の公開候補から外す。
7. 修理ID単位では、内装候補ID集合と外装候補ID集合を作り、only/both/eitherを集計する。

## 集計結果

今回、実データを読み取り専用で一次集計した。

| 項目 | 件数 |
| --- | ---: |
| FMP CSV行数 | 3886 |
| FMP過去データの修理ID総数 | 3886 |
| 内装修理明細の総数 | 3242 |
| 外装修理明細の総数 | 1376 |
| 内装修理ルールにより掲載候補になる明細数 | 2621 |
| 外装修理ルールにより掲載候補になる明細数 | 710 |
| 内装または外装のどちらかに掲載候補がある修理ID数 | 2921 |
| 内装のみ掲載候補がある修理ID数 | 2243 |
| 外装のみ掲載候補がある修理ID数 | 477 |
| 内装・外装の両方に掲載候補がある修理ID数 | 201 |

内装候補2621件は、`掲載候補` 2618件と `掲載候補（要最終確認）` 3件を合算したCSV突合値。内装Excelの `掲載方針_概要` には掲載候補の明細件数合計2624件とあるため、基準ファイル差または原文完全一致差と思われる3件差がある。

候補外明細の一次整理は以下。

| 区分 | 件数 |
| --- | ---: |
| 内装: 掲載対象外判定 | 396 |
| 外装: 掲載対象外・内装修理へ移動判定 | 38 |
| 掲載対象外になる明細数（明示判定のみ） | 434 |
| 外装: 確認済みだが表示名空欄等で候補化保留 | 70 |
| 内装: 未レビューのため掲載しない | 214 |
| 外装: 未確認・ルール未一致のため掲載しない | 558 |
| 未レビュー/未確認のため掲載しない明細数 | 772 |
| 内装: ルール完全一致なし | 11 |

内装の完全一致なし11件は、改行や制御文字を含む原文差の可能性があるため、次タスクで正規化方針を確認する。

## 注意点

- 99件を公開事例数と誤解しない
- 未レビュー221種類は掲載しない
- 外装修理も対象
- 未完成マスタへ接続しない
- B2B事例とB2C事例は別に扱う
- B2Bは価格を公開し、技術料と部品代を分ける
- B2Cは価格を公開しない
- 顧客名、電話番号、住所、メール、顧客管理番号、内部メモ、備考、連絡事項、取引先情報、仕入価格、原価、利益などは公開候補に出さない
- 外装候補710件は、確認結果と表示名があるものだけを候補扱いした厳しめの一次集計
- 外装修理の確認済み68種類すべてがそのまま公開候補ではない
