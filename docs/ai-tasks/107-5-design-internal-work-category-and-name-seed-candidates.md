内装作業マスタの実装前に、初期投入する作業カテゴリ・作業名・表示名のseed案をMarkdownで設計する。

今回の成果物はseed実装ではなく、初期投入候補の設計メモ。

## 107-4の結論整理

Task 107-4では、内装作業マスタの最小モデルとして以下を推奨した。

- `WorkCategoryMaster` は `parentId` ありの階層型。
- `WorkNameMaster` は初期は完成作業名で持つ。
- `targetLabel` / `actionLabel` / `treatmentLabel` はoptionalで残す。
- `PricingRule` は作業マスタ本体にせず、価格ルールとして残す。
- `PricingRule.workNameId` は将来的な追加候補。
- 明細側には、作業マスタ参照ID、表示名、価格表示フラグをスナップショット保存する。

この107-5では、`WorkCategoryMaster` / `WorkNameMaster` に最初に入れる候補だけを整理する。

## ドリルダウン表示案

初期UIでは以下の見え方を想定する。

1. 大分類: `内装修理`
2. 中分類: `基本整備` / `精度・歩度` / `巻上げ・針回し` / `自動巻機構` / `輪列` / `香箱・動力` / `脱進調速` / `カレンダー` / `電池・電子回路` / `防水・機能検査` / `部品交換技術料` / `その他内装修理`
3. 作業名: 選択中カテゴリの `initialSeed = yes` を優先表示し、検索入力時に `review` 候補も出せる設計を検討する。

検索例:

- `精度` -> `精度調整`、`精度検査`
- `精度調` -> `精度調整`
- `裏押` -> `裏押さえ交換技術料`、`裏押さえネジ交換技術料`
- `電池` -> `電池交換`、`二次電池交換`、`電池押さえ交換技術料`

## 表示名設計

基本方針:

- `internalName` は社内用の正確な名称。
- `estimateDisplayName` は帳票用。細かすぎる部品交換では `部品交換技術料` に丸めてもよい。
- `b2bDisplayName` は専門用語を出してよい。
- `b2cDisplayName` は一般顧客向けに粗くする。
- `publicCaseDisplayName` は初期seedでは原則持たず、B2B/B2C表示名から生成する。

表示名の例:

| 種類 | 例 |
|---|---|
| internalName | 裏押さえネジ交換技術料 |
| estimateDisplayName | 部品交換技術料 |
| b2bDisplayName | 裏押さえネジ交換 |
| b2cDisplayName | 巻上げ機構修理 |
| publicCaseDisplayName | 初期は空。必要時にB2B/B2Cから生成。 |

B2Cは必ず細かい部品名を隠すわけではないが、公開事例では丸める前提を強める。

## targetLabel / actionLabel / treatmentLabel 案

初期seedに含める推奨:

- `targetLabel`: yes
- `actionLabel`: yes
- `treatmentLabel`: yes

理由:

- WorkNameMasterは完成名で持つが、将来の分析・PublicCase生成・検索補助に使える。
- 独立した `WorkActionMaster` / `WorkTreatmentMaster` を作らなくても、初期seedの列として持てる。
- 「交換技術料」系で対象部品と処置を分けておくと、部品明細との紐づけがしやすい。

代表例:

| workName | targetLabel | actionLabel | treatmentLabel |
|---|---|---|---|
| ゼンマイ交換技術料 | ゼンマイ | 交換 | 交換 |
| カンヌキ修正 | カンヌキ | 修正 | 修理 |

## 五番車の扱い

方針:

- 五番車はクォーツカテゴリで採用する。
- 機械式輪列カテゴリには初期採用しない。
- 機械式で該当が出た場合は、伝え車 / 中間車 / 出車など既存名称で扱えるか確認し、必要時のみ追加検討する。

作業名への反映:

- `内装修理 > 輪列 > 五番車交換技術料`: `initialSeed = no`
- `内装修理 > 電池・電子回路 > 五番車交換技術料`: `initialSeed = yes`

ただし、電池・電子回路カテゴリに「クォーツ輪列」相当のサブカテゴリを後で追加するかは要検討。
