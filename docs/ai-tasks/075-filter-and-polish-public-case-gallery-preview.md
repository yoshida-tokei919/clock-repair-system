# AI Task 075: PublicCaseギャラリープレビューの表示対象分類と改善

## 目的

FMP PublicCase sample JSONを使った開発用ギャラリープレビューで、B2C公開事例として見せるべき候補と、B2B価格事例として使う候補を分けて確認できるようにする。

今回はDB接続、DB更新、migration、seed、API、本番公開ページ接続は行わない。

## 前提

- 対象ページは開発用の `/dev/public-case-gallery-preview`
- 既存の `/cases/gallery` や `/cases/biz` は変更しない
- 入力は生成済みsample JSONのみ
- CSV / Excel / JSON本体は変更しない
- B2Cでは価格を表示しない
- B2Bでは `showPriceB2b = true` かつ正の金額がある明細だけ価格表示する

## B2C表示候補の条件

B2C表示候補は、以下を満たすCaseに分類する。

- B2Cで使える作業名がある
- 作業名が「修理内容確認中」ではない
- `技術料`、`○○`、読み仮名混入疑いを主表示に使わない
- warningがない
- モデル名またはRefがあり、カードタイトルとして成立する

写真は現時点のsampleでは未設定が多いため、分類の必須条件にはせず、並び順で写真ありを優先する。

## B2C要確認の条件

以下に該当するCaseは、B2C公開候補とは別の「B2C要確認カード」に分類する。

- モデル名がない
- 写真がない
- warningがある
- unlinked PartItemがある
- 作業名が弱い
- Ref / Calだけでは公開カードとして分かりづらい

## B2C非表示候補の条件

以下に該当するCaseは、開発用の「B2C非表示候補」に分類する。

- 表示できるB2C作業名がない
- モデル名がなく、Refもなく、作業名も弱い
- B2C表示名に `技術料`、`○○`、読み仮名混入疑いがある
- 写真なしで情報量も弱い

## B2Cカードタイトル生成ルール

「モデル情報なし」を主タイトルに出さないため、以下の優先順位でタイトルを作る。

1. モデル名
2. ブランド + `Ref. xxx`
3. ブランド + 作業名
4. ブランド + `修理事例`

Ref / Calはカードタイトルではなく、小さな補足欄に表示する。

## B2C並び順

B2Cカードは以下の優先順位で並べる。

1. 写真あり
2. warningなし
3. モデル名あり
4. B2C作業名あり
5. Refあり
6. Calあり

## B2Bカード改善

B2B価格事例カードも「モデル情報なし」を主タイトルにしない。

タイトルは以下の優先順位で作る。

1. ブランド + モデル名
2. ブランド + `Ref. xxx`
3. ブランド + 作業名
4. ブランド + `修理事例`

価格は `showPriceB2b = true` かつ正の金額がある技術料・部品代だけ表示する。

価格表示対象がない場合は、技術料0円、部品代0円、合計0円を出さず、「価格表示対象なし」と表示する。

unlinked PartItemは要確認扱いにし、価格は表示しない。

## 件数表示

プレビュー上部に以下を表示する。

- sample総数
- B2C表示候補
- B2C要確認
- B2C非表示候補
- B2B価格表示候補
- warningあり
