# AI Task 080: PublicCaseプレビューのRef/Cal重複表示修正

## 目的

`/dev/public-case-gallery-preview` のB2C / B2Bカードで、モデル名がない場合に `Ref.` や `Cal.` がタイトルと補足欄に二重表示されないようにする。

## 問題点

モデル名がないCaseでは、タイトル生成で `Ref. xxxx` を使い、補足欄でも同じ `Ref. xxxx` を表示していた。

例:

- `SEIKO`
- `Ref. 1400-5050`
- `Ref. 1400-5050`

これはカード内で同じ情報が重複し、公開事例として見づらい。

## 修正したタイトル生成ルール

タイトル生成を、文字列だけでなく「タイトルにRef/Calを使ったか」を返す形にした。

優先順位は以下。

1. モデル名
2. Ref
3. Cal
4. 作業名
5. 修理事例

## Ref / Cal 補足表示ルール

補足欄は、タイトルに使っていないRef / Calだけを表示する。

- タイトルにRefを使った場合、補足欄ではRefを省略する
- タイトルにCalを使った場合、補足欄ではCalを省略する
- モデル名がある場合は、補足欄にRef / Calを表示する

## B2C表示への影響

B2Cカードでも同じルールを適用した。

価格表示は追加していない。

## B2B表示への影響

B2Bカードでも同じルールを適用した。

価格表示ルール、合計計算、`交換部品` ラベルは変更していない。

## 変更しなかったもの

- DB接続・DB更新
- migration / seed
- Supabase接続
- `prisma/schema.prisma`
- CSV / Excel / JSON本体
- 既存公開ページ
- FMP公開候補生成ロジック
- B2B価格表示ルール
- `交換部品` ラベル
