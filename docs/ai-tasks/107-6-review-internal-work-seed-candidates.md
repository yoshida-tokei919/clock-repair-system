# AI Task 107-6: 内装作業seed案のユーザーレビュー用チェックリスト

## 概要

Task 107-5で作成した内装作業カテゴリ・作業名seed候補を、実装前にユーザーが確認しやすい形へ整理する。

このレビュー表では、以下を確認する。

- 初期seedに入れる作業名
- review扱いにしている作業名
- no扱いにしている作業名
- alias候補
- B2B/B2C表示名の粒度
- カテゴリ配置
- 五番車の扱い
- 部品マスタ追加候補との整合

今回もMarkdown作成のみ。schema、seed、API、UI、DBは変更しない。

## レビュー方法

各表の `ユーザー判断` 欄に、以下のような判断を入れる想定。

| 判断 | 意味 |
|---|---|
| OK | 現在案でよい。 |
| 変更 | 名称・表示名・カテゴリなどを変更したい。 |
| 後回し | 初期seedには入れない。 |
| 不採用 | 今後も基本的に入れない。 |
| 要相談 | 追加で実務確認が必要。 |

特に見てほしい観点:

- 作業名が実務入力で探しやすいか。
- 帳票表示名が顧客向けに自然か。
- B2B表示名が業者向けに十分具体的か。
- B2C表示名が粗すぎないか。
- 部品交換技術料と部品明細の分担が自然か。
- 機械式とクォーツの分類が混ざっていないか。
