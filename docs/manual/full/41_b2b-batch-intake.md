# 第41章 B2B一括受付と管理タグ印刷

## 41.1 対象と開始場所

管理者は修理案件一覧から「B2B一括受付」を開き、`/repairs/b2b-intake`で**同じ既存取引先の時計を1～30本**まとめて登録できる。時計現物と取引先を照合してから始める。取引先は登録済みのB2Bパートナーから選び、この画面では新しい取引先を作成しない。

## 41.2 時計ごとの入力

「時計を追加」で行を増やし、各時計を入力する。ブランドは必須。取引先管理番号、エンドユーザー名、モデル、Ref、シリアル、時計Cal、Calメーカー・Cal、Base Calメーカー・Base Cal、依頼内容は必要な内容を確認して入力する。「依頼内容」は修理案件の作業概要として保存される。

ブランド、モデル、Ref、時計Cal、ムーブメントメーカーとCal、ベースメーカーとCalは候補を検索でき、候補がなければ自由入力できる。時計ブランドを選ぶとモデル等の候補が絞られ、RefにCalが紐付く場合は時計Calが補完される。補完後も手動修正できる。ブランドやモデルを変更すると下位項目は消えるため、再確認する。候補は矢印キーで移動、Enterで選択、Escapeで閉じられる。自由入力した値は「一括受付」ボタンで登録する。

登録前に、行数、取引先、時計と各依頼内容の対応を確認する。登録処理はバッチ単位で行い、途中で一部の時計だけが成功した状態にはしない。通信結果が不明、またはサーバーエラーのときは**同じバッチを盲目的に再送せず**、修理案件一覧で登録結果を調べる。

## 41.3 登録結果とPhysicalTag

成功画面には、登録した全Repairの受付番号と案件リンクが一覧表示される。登録直後の状態は「受付」。**受付完了だけではPhysicalTagの準備もラベル印刷も始まらない。** 現物と結果一覧を照合してから「管理タグを準備して印刷」を明示的に押す。

準備では既存の有効なPhysicalTag割当を再利用し、タグがない案件にだけ新規発行する。登録結果の順に、Brother QL-800へ1枚ずつ62 × 75 mmラベルを直接印刷する。完了件数、既存タグの再利用件数、各受付番号とshortCodeを画面で確認し、印刷物を現物と照合する。プリンターと用紙の準備は[第19章](19_ql800-label.md)を参照する。

途中の1枚で印刷例外が出た場合は後続を停止し、その1枚を「印刷結果不明」と表示する。**出力済みの可能性があるため自動再試行しない。** 現物を確認し、「現物で印刷済みを確認」または「この1枚を明示的に再印刷」を選ぶ。その後「未試行の残りを印刷」で続ける。全件完了後の「再印刷」は全件を再び印刷する操作なので、必要な場合だけ使う。準備をやり直しても有効なタグを再利用する。

単件のQL-800直接印刷とオートカットは実機確認済み。**複数枚の連続印刷は実機では未確認**のため、初回の実バッチでは各枚の出力と対応関係を確認する。
