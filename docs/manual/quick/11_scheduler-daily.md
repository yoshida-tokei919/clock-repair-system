# 簡易版 11 — 作業カレンダーと予定案を確認する

## 目的

今日・今後の修理作業を、実際の作業可能時間と納期に合わせてScheduler v2へ反映する。

## 1. 作業カレンダーを確認

`作業カレンダー` を開く。

通常日は8時間。休み・半日・私用等がある日だけ変更する。

![Work calendar](../assets/screenshots/work-calendar.png)

- 休み: 0h
- 半日: 4h
- 通常: 8h
- 必要なら任意時間とメモを入力

## 2. Scheduler v2予定案を表示

同じ画面の `Scheduler v2 分割予定案` で `予定案を表示` を押す。

![Scheduler v2 preview](../assets/screenshots/scheduler-v2-preview.png)

主に確認する項目:

- 作業待ち案件が入っているか
- 部品待ちの最短開始日が正しいか（入荷見込み日不明なら配置されていないか）
- 中断案件が除外されているか
- 納期に間に合うか
- 提案segmentの日付・分数
- 配置不可の理由

## 3. 時間の推奨差が大きい場合

`保存 ○分 → 推奨 ○分` の差が大きい場合は、案件詳細の作業時間プレビューを確認する。

推奨時間は自動採用されない。

必要なら案件詳細で `推定時間を採用` してから予定案を更新する。

## 4. 予定案を反映

内容に問題がなければ `N件の予定を反映` を押す。

確認dialogでもう一度件数を確認する。

予定案取得後に条件が変わっていた場合は反映が拒否され、新しい予定案へ更新される。

その場合は内容を確認してから再度反映する。

## 注意

- 固定予定は自動変更されない
- 手動segmentは保護される
- 部品入荷見込み日が分かるWAITINGは、その日以降の将来予定に入る場合がある
- 部品状態・見込み日が不明なら無理に予定へ入れない
- 中断中は自動再開しない
- 古い予定案を自動で再送信しない
