# 簡易版 6 — 見積明細を作成・送信する

## 目的

現物確認後に修理内容と金額を入力し、顧客へ正式な見積共有URLを送る。

## 1. 見積・修理明細を入力

Repair詳細の「見積・修理明細」で必要な行を追加する。

主な区分:

- 技術料
- 外装修理技術料
- 交換部品

![Estimate entry](../assets/screenshots/estimate-entry.png)

各行の上代・個数を確認し、必要なら備考を入力する。

## 2. お客様への説明を入力

故障原因や注意事項など、顧客へ伝える内容は「お客様連絡」へ入力する。

社内だけの情報は「社内メモ」へ分ける。

## 3. Repairを保存

通常、受付済み案件へ見積明細を入力して保存すると `見積中` へ進む。

## 4. 見積書を作成

1. 修理一覧へ戻る。
2. 対象Repairをチェックする。
3. 「見積書作成」を押す。
4. 見積書画面を開く。

## 5. PDFを生成して確認

見積書画面で、

1. 「PDFを生成」
2. 「PDFを開く」
3. 金額・時計・明細・説明を確認

の順で確認する。

![Estimate document actions](../assets/screenshots/estimate-document-actions.png)

## 6. LINEで送信

PDF確認後に「LINEで送信」を押す。

LINEへPDFを直接添付するのではなく、顧客用共有ページURLを送る。

**注意:** ボタンを押した直後は送信完了ではない。送信待ちへ登録され、LINE Managerで実送信確認できた後にRepairが `承認待ち` へ進む。
