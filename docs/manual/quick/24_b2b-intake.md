# 簡易版 24 — B2B一括受付

1. 修理案件一覧から「B2B一括受付」を開き、登録済みの取引先を選ぶ。同じ取引先の時計を1～30本登録できる。
2. 時計ごとにブランド（必須）、取引先管理番号、エンドユーザー名、モデル、Ref、シリアル、時計Cal、Calメーカー・Cal、Base Calメーカー・Base Cal、依頼内容を確認して入力する。マスター候補を検索して選ぶか、自由入力する。
3. 「一括受付」を押し、結果一覧の全受付番号と案件リンクを現物と照合する。通信結果不明時は同じバッチを再送せず、案件一覧で確認する。
4. 必要なら結果画面の「管理タグを準備して印刷」を押す。既存の有効なタグは再利用され、未割当の案件だけ新しいタグが準備される。ラベルはQL-800へ順に1枚ずつ印刷される。
5. 印刷結果不明の1枚が出たら止めて現物を確認する。その1枚を明示的に再印刷するか、印刷済みを確認してから未試行分を続ける。自動再試行はしない。

受付完了だけではタグも印刷も開始しない。単件の直接印刷は実機確認済みだが、複数枚連続印刷は実機未確認。詳しくは[詳細版第41章](../full/41_b2b-batch-intake.md)。
