# 簡易版 23 — 顧客のLINE履歴と返信

1. 顧客一覧・顧客編集の「やり取り」からCustomer Communication Hubを開く。顧客に紐付く複数のLINEユーザーと、終了済みを含むInquiryの保存済み履歴を確認する。新しい500件を超える場合は古い履歴の警告が出る。
2. 「LINE送信待ち・結果確認中」は送信済みの証拠ではない。送信済みかは確認済み履歴で確かめる。
3. 返信する場合は送信先を確認し、本文を入力して「LINE送信待ちに登録」を押す。確認済みの送信先や既存Inquiryがない場合は返信できない。
4. 特定の修理に関する会話はRepair詳細のLINE欄を見る。ここには、そのRepairに関連付けられた別Inquiryの受付後メッセージも表示される。顧客全体の履歴と表示範囲が異なる。

受付前の時計ごとのLINE分類はInquiryレビューで操作できる。受付後メッセージのRepair関連付けを操作する管理画面はまだない。詳しくは[詳細版第40章](../full/40_customer-communication-hub.md)。
