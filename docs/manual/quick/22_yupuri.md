# 簡易版 22 — ゆうプリR CSVの現在の使い方

## V3出力

管理者認証がある環境で、対象発送IDの `GET /api/shipments/[id]/yupuri-v3` からゆうプリR標準フォーマットV3 CSVを取得できる。`/shipments` に共通の出力ボタンは **まだない**。API操作環境がない場合は管理責任者に取得方法を確認する。

出力対象は **OUTBOUND・未発送（`actualShippedAt = null`）で、statusが `DRAFT / READY / LABEL_ISSUED / AWAITING_ACCEPTANCE` のいずれか**。出力は100列、CP932 / Shift_JIS、BOMなし、CRLF。お客様側管理番号は `SHP-{id}`。宛先と配達希望を確認してからゆうプリRへ取り込む。荷物サイズコードは現時点で `060` 固定なので、60サイズ以外の荷物にはそのまま使わない。CSV出力だけでは発送状態は変わらない。

## 発送履歴の確認

`/shipments` の「ゆうプリR 発送履歴CSV」で1ファイルを選び、「プレビュー」を押す。結果のShipment、追跡番号の現在値と候補、公式状態、警告・エラーを確認する。**読取専用**でapply操作はない。`10/0A = 引受予定`は実引受ではない。状態の比較候補や`importableLater`は更新可否・承認を意味しない。日付値は生値のままで、追跡番号や発送日、配達完了日、Shipment / Repair statusを書き戻さない。

**現在の限界:** 出力・プレビュー以降の送り状操作、実際の引渡し、追跡・配達完了は自動連携が完成していない。実物とゆうプリR側の結果を確認し、アプリに自動記録されたものとして扱わない。

発送後の現行確認手順と未実装範囲は、詳細版の[第26章「発送・追跡・配達完了 — 現行運用と制限」](../full/26_shipping-tracking-delivery.md)を参照する。
