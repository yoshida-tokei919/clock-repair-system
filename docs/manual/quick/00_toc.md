# 簡易版 目次案

目的: 初めて操作する人でも、この冊子を見ながらB2C案件をLINE問い合わせから返送・納品まで処理できるようにする。

内部DB・API・n8n等の詳細は原則として詳細版へ分離する。

## 問い合わせ・受付

1. LINE問い合わせを確認する
2. 受付レビューを開く
3. AI候補と時計情報を確認・確定する
4. 時計ごとに「受付希望 / 保留 / お断り」を決める
5. お客様用受付リンクを発行してLINEで案内する
6. 顧客入力後のRepair「送付待ち」を確認する
7. 現物到着後にRepairを「受付」へ変更する
8. PhysicalTagラベルを発行・取り付ける
9. 保管場所を登録する

## 見積・承認

10. 修理明細を入力する
11. 見積を確認・送付する
12. 顧客承認を確認する
13. 部品が必要な場合は発注・部品待ちにする

## 修理作業

14. 今日の作業を確認する
15. PhysicalTagをscanする
16. タイマーを開始・切替・停止する
17. 修理作業を完了する
18. ランニングテスト・最終確認を行う

## 発送・納品

19. 作業完了をLINE連絡する
20. 顧客の配達希望日時を確認する
21. Shipmentを作成・確認する
22. 梱包対象を連続scanして照合する
23. PhysicalTagをreleaseする
24. ゆうプリR CSVを出力する
25. 送り状を発行する
26. 発送・追跡状況を確認する
27. 配達完了・Repair納品完了を確認する

想定ページ数: 表紙・目次を含め約27〜32ページ。原則1工程1ページとし、複雑な画面だけ見開き2ページを使用する。
