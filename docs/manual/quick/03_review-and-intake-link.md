# 簡易版 2 — 受付レビューと受付リンク

## 目的

AI候補を確認して時計情報を確定し、受付する時計だけを顧客用受付リンクへ載せる。

## 1. AI候補を確認する

時計ごとに、ブランド・モデル・Ref.・ケースRef・Cal.・Base Cal.・不具合候補・依頼内容・不足情報を確認する。

AI候補は参考情報であり、そのまま正式値ではない。

`[画面画像予定: inquiry-review-watch-candidates.png]`

## 2. 時計情報を確定する

1. AI候補と根拠を確認する。
2. 必要なら手入力で修正する。
3. Brand / Model / Ref / Cal.等は既存masterを選択する。
4. 未登録masterが必要な場合は、新規登録内容を確認して明示登録する。
5. 正しい値になったら「この値を確定」を押す。
6. 「この時計の確認内容を保存」を押す。

確定済み・手入力済みの値は、後続のAI再解析から保護される。

## 3. 受付判断を行う

「B2C 受付判断」で時計ごとに次のいずれかを選ぶ。

- **受付希望** — 修理品の送付を案内する
- **保留** — まだ判断しない
- **お断り** — 今回は受付しない

受付リンクには `受付希望` の時計だけが含まれる。

## 4. 受付リンクを発行する

1. 「お客様用受付リンクを発行」を押す。
2. 表示された対象時計と有効期限を確認する。
3. LINE送信用案内文をコピーする。
4. 顧客へのLINE返信として送信待ちに追加する。

`[画面画像予定: inquiry-intake-invite-dialog.png]`

## 5. 受付内容を後から変更した場合

受付リンク発行後に対象時計を変更した場合、古いリンクを使い続けない。

アプリは現在の受付希望時計と一致しない古いリンクを無効化するため、最新の受付リンクを確認して案内する。

## 注意

**受付リンクを発行した時点ではRepairはまだ作成されない。**

顧客が受付ページへ必要事項を入力し、送信した時点でWatch / Repairが作成される。
