# 簡易版 13 — 作業タイマーを開始・切替・停止する

## 目的

修理・見積・受付・問い合わせ等の実作業時間をWorkTimeSessionへ正しく記録する。

## 1. 現在のタイマーを確認

画面上部の共通タイマーバーを見る。

![Work timer bar](../assets/screenshots/work-timer-bar.png)

active中は活動名・作業名・経過時間を表示する。

## 2. Repairの修理作業を開始

Repair詳細の「作業タイマー」を開く。

![Repair work timer](../assets/screenshots/repair-work-timer.png)

- 見積作業 → `見積開始`
- 技術料明細の修理 → 該当行の `修理開始`

交換部品行そのものは修理タイマー対象ではない。

## 3. 別作業へ切り替える

別のタイマーを開始すると、現在のactive sessionを終了して新しい作業へ切り替わる。

同時に2本のタイマーは動かない。

## 4. 共通業務を開始

上部バーから直接開始できる。

- 受付
- 顧客連絡
- 発送
- 事務
- その他

問い合わせ対応はInquiryレビュー、発注作業は発注管理の専用ボタンを使う。

## 5. 作業を止める

休憩・作業終了時は上部バーの `停止` を押す。

ページを移動しただけではタイマーは止まらない。

## 6. 表示がおかしい場合

通信エラー等で現在状態が分からない場合は、何度も開始ボタンを押さず `再取得` する。

サーバー側のactive sessionを確認してから続ける。

## 注意

- active sessionはアプリ全体で最大1件
- 別作業開始はswitchになる
- 作業開始直前・終了直後に操作する
- 予定時間ではなく実際に作業した時間を計測する
