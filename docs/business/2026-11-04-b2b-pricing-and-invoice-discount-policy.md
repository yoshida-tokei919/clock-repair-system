# B2B料金改定・インボイス割引の運用決定（2026-11-04）

- 決定日：2026-11-04
- 対象：ヨシダ時計修理工房のB2B取引（既存取引先／新規取引先）
- 文書種別：業務方針・実装引き継ぎ
- 状態：**料金方針は決定済み。アプリ改修・本番請求書の修正は別Taskで実施予定（本書の保存時点では未実施）。**
- 注記：この文書は価格改定と割引運用の決定記録であり、税務上の個別判断は取引先・税理士等に要確認。

## 1. 決定事項（業務方針）

| 項目 | 決定内容 |
| --- | --- |
| B2B税抜基本料金 | 現行から **6%引き上げる** |
| インボイス未登録を踏まえた請求書割引 | 従来 **2%** → 原則 **3%** |
| 既存B2B取引先の新基本料金 | **2027-04-01** から |
| 新規B2B取引先の新基本料金 | **2026-11-04以降の新規取引先** には初回から |
| 料金見直し基準日 | 毎年 **4月1日** |
| 次回以降の改定 | 年1回検討。目安は年 **2～3%程度**だが、毎年の値上げや改定率を確約・自動適用しない |
| 2026年10月末締め請求書 | 原則 **3%割引に見直す方針**。対象取引日・発行／送信／入金状態を確認してから修正 |
| 既存見積・請求 | 過去の確定額を自動的に変更しない。発行済・送信済・入金済の訂正は個別に判断 |

**重要：** 基本料金の「6%改定」と請求書の「3%割引」は異なる施策で、適用時期を混同しない。既存取引先については2027年3月31日まで原則旧基本料金のまま、該当する請求書のインボイス割引は別途3%へ見直す。

## 2. 判断の背景

- B2B技術料金を10年以上大きく改定しておらず、部品・消耗品等のコスト上昇を近年強く感じている。
- 知り合いの同業者の料金は工房と大差がなく、公開されている同業B2B外注価格も少ない。業界全体の値上げ幅を確認した事実はない。
- 一度に10%以上値上げすることは継続取引先の心理的負担が大きいと考え、段階的な改定を選択した。
- 将来は毎年4月1日を基準に採算・物価・仕入価格・作業時間・取引関係を評価する。

## 3. 割引と値上げの試算（端数処理前・税抜ベース）

旧基本料金を20,000円、旧割引を2%とする例。

| 区分 | 計算 | 税抜の割引後金額 |
| --- | --- | ---: |
| 改定前 | 20,000円 × (1 - 0.02) | 19,600円 |
| 改定後（6%値上げ＋3%割引） | 20,000円 × 1.06 × (1 - 0.03) | 20,564円 |
| 差額 | 20,564円 - 19,600円 | +964円 |

現行の2%割引後と比較した工房の税抜請求額増加率は **約4.92%**。消費税、税込固定価格、端数処理については既存帳票仕様と取引先契約を確認する。

**税抜金額を割引の基礎とする点は、事業者の記憶上の現行運用であり、実装調査で確認すること。** 計算方法を未検証のまま変更・断定しない。

## 4. インボイス制度との関係（税務制度と営業割引を分離）

工房は現時点でインボイス発行事業者として未登録。取引先の仕入税額控除の一部が制限される可能性を考慮し、工房の営業上の価格調整として割引を行っている。**税法が3%の割引を一律に義務付けているわけではない。**

国税庁の2026年度税制改正資料による経過措置（対象となる課税仕入れについての控除可能割合）：

| 区分 | 控除可能割合 |
| --- | ---: |
| 2026-09-30まで | 80% |
| 2026-10-01～2028-09-30 | 70% |
| 2028-10-01～2030-09-30 | 50% |
| 2030-10-01～2031-09-30 | 30% |
| 2031-10-01以降 | 0% |

**注意：** 2026年改正の適用には **取引先の「2026年10月1日以後に開始する課税期間」** などの要件がある。控除割合は請求書の締め日だけでは決まらない。修理役務の完了日・引渡日等の取引時期、取引先の課税方式（原則課税／簡易課税）、少額特例、契約条件その他により影響が異なる。3%は一般的な10%課税取引で控除70%を想定した概算上の配慮であり、個々の取引先の実損を保証しない。

参考：国税庁 [令和8年度税制改正特集](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/invoice-review/index.htm) ／ [インボイス制度Q&A目次](https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/qa_invoice_mokuji.htm)

## 5. 2026年10月末締め請求書の実務

- 通常請求書・集約請求書の両方について、現在の2%適用状況と3%適用対象を調査する。
- **2026年10月の請求対象取引のうち、9月以前の役務完了等が混在しないか**、また相手先の課税期間等を確認する。
- 下書き・未発行分は修正可能にする。発行済／送信済／入金済は**無断更新せず**、訂正・再発行方針を報告し承認を受ける。
- 割引率変更によって既存のPDF・共有ページ・集約請求書・請求合計が矛盾しないようにする。
- 請求書単位の割引率と割引額は発行時点の記録として固定し、後日の設定変更では変動させない。

## 6. アプリ機能に関する合意した依頼内容（実装は別Task）

次の内容を別チャットでCodex中心に調査・実装する依頼文まで作成済み。**実装完了・デプロイ済みを意味しない。**

1. 標準インボイス割引率を管理画面で設定可能にする（初期3%、0%・小数にも対応）。
2. 取引先別に標準／個別割引率を選択できるようにする。
3. 請求書作成時に個別割引率を確認・調整可能とする。適用優先順は請求書指定 ＞ 取引先指定 ＞ 標準設定。
4. 通常請求書・集約請求書・PDF・共有ページで同一の計算結果にする。過去発行済みの請求金額は自動変更しない。
5. あしや時計宝石修理研究所など、技術料の税込固定や部品代の個別課税ルールを破壊しない。
6. 割引率の設定変更と既存請求書の訂正を分離し、production DB変更／migration／deployはユーザーの明示承認後に実施する。
7. **6%の基本料金改定は本割引率Taskの対象外。** 別Taskで顧客区分・適用開始日・見積snapshot・価格マスタの影響を検証する。
